# feedpakr — AI Agent Guide

## Versioning

Bump `version` in `plugin.json` whenever a change is user-visible — new
import capability, a fixed bug that affected real output, a changed UI
flow. It was left at `0.1.0` from the very first commit through 9
subsequent commits (four full feature phases) before anyone noticed —
don't let it go stale again. Patch (`0.1.x`) for fixes, minor (`0.x.0`)
for new features, matching normal semver-during-0.x conventions.
